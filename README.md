# 小阅助 v5.0.0

100% 离线 Android 答题卡批改系统。拍照即可自动识别填涂并判分，无需网络。

## 核心优势：模板卷校准，彻底解决打印偏差

不同打印机、不同纸张、不同缩放比例，打印出来的答题卡气泡位置会有微小偏移。传统方案依赖预设坐标，只要打印有偏差，识别就会出问题。

**小阅助的解决方案：**

```
打印答题卡 → 老师填一份"标准卷"（学号 00，选择题填正确答案）
    → 拍照校准 → 系统自动发现所有气泡的精确位置和正确答案
        → 保存为批改模板 → 后续学生卷都用此模板批改
```

模板来自**真实打印稿**，有多少偏差系统就适应多少偏差。这是任何固定坐标方案无法做到的。

## 核心算法：最大间隙自适应阈值

填涂判定采用了 [OMRChecker](https://github.com/Udayraj123/OMRChecker)（GitHub 1.1k+ stars）的经典思路：

```
每行气泡测像素强度 → 降序排序 → 找相邻值之间最大跳跃 → 阈值 = 跳跃中点
```

**为什么不用固定阈值？** 传统方案设置"亮度低于 50% 算填涂"，但不同光线、不同铅笔深浅会让固定阈值失效。最大间隙算法完全数据驱动：填涂和空白之间的自然分离点就是阈值，无论光照如何变化。

双层阈值：全局分离点 + 每题行局部分离点，局部不可靠时回退到全局。

### 设想的改进方向

可进一步增加可靠性：不只测气泡内部平均亮度，而是**对每个气泡区域的像素做黑白排序，取中位数附近的连续区间判断填涂状态**。这样能更精细地区分"涂了一半"和"彻底涂满"的边界情况，减少误判。

## 功能

- 自定义答题卡：题目数量、每题选项数（2-8）、每题分值（支持小数）、正确答案（支持多选）
- 班级管理：创建班级、导入学生名单（学号自动递增）
- 模板卷校准：打印后扫描一份填写了正确答案的标准卷
- 拍照批改：CameraX 实时流，自动检测边框、触发识别
- 成绩分析：逐题对错、易错题排行、真实分数分布、及格率
- 完全离线：无需网络，数据本地存储

## 技术栈

Kotlin · Jetpack Compose · CameraX · OpenCV 4.5.3 · Room · Hilt · MVVM

## 使用流程

1. 创建答题卡 → 设置题目和答案 → 导出打印
2. 老师填一份标准卷（学号 00，正确答案）→ 校准
3. 创建班级 → 导入学生
4. 选择班级和答题卡 → 扫描学生卷 → 自动判分
5. 在班级详情查看成绩和分析

## 注意事项

- ☀️ 光线充足均匀，避免阴影
- 📐 答题卡平放，避免折痕卷曲
- ✏️ 用铅笔或黑色笔填满气泡
- 📱 手持手机保持稳定，等待自动触发
